Customer records desk

Staff sign-in. Every request to this desk is screened for SQL injection before it reaches customer data.

What a request passes through

  1. AWS WAFDrops requests that match SQL injection signatures before they reach the server.
  2. Application filterScores what gets through, flags the doubtful, rejects the obvious.
  3. Parameterised queriesUser input is sent as data, never as part of the SQL text.
  4. Least-privilege database roleNo schema changes, no deletes, no access to password hashes.
  5. Masked outputIdentifiers leave the API masked; heavy reading pauses the account.
